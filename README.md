# WiFi-CSI-sensing
playing around with WifFi channel state information to see If i can pick up movement with the wireless signals that are everywhere nowdays. 
## Third-Party Software

This project uses Espressif's ESP-CSI framework and ESP-IDF for Wi-Fi Channel
State Information acquisition on ESP32-C5 hardware.

ESP-CSI:
https://github.com/espressif/esp-csi

ESP-IDF:
https://github.com/espressif/esp-idf
